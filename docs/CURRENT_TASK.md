# P07 · 消息中心与好友一对一聊天

> 说明：本文件为从《美食家园》产品需求派生的阶段实施安排，阶段划分与顺序是执行规划，非原始需求新增功能。
> 产品权威来源：`docs/requirements/product/01-roles-and-functions.md`、`02-pages.md`、`03-quality-and-appendices.md`。

## 阶段目的
交付消息列表、一对一好友聊天和预订通知的承载能力，为 P08 预订事件接入准备稳定消息视图。

## 本阶段完整工作范围
1. 消息底部导航展示与好友的聊天记录及预订通知，点击消息条目进入对应聊天详情页。
2. 好友之间可进行一对一的文字实时聊天；发送、接收和历史展示遵守登录状态、好友权限和用户隐私。
3. 无会话、加载失败、断网、重连时提供明确状态；避免将一次发送结果渲染成多条已发送消息，不能把失败伪装为成功。
4. 通知已是原有需求，但其形式（消息列表独立项、聊天内事件或两者共存）、未读与已读回执属于【待确认】；本阶段只实现已确认载体和用户认可的实际呈现，不强行加群聊或推送系统。
5. 预订通知与订单关联需保留一致的身份/关联契约；P08 负责真实订单事件接入，不提前虚构下单流程。

## 验收要点
- 与正确好友的一对一聊天工作，历史显示与真实消息一致；拒绝陌生人/无权访问。
- 消息列表跳转准确，通知承载入口明确，网络错误能够恢复而不重复成功项。
- UI Gate 提供发送/接收/断网恢复及相关通知入口检查。
