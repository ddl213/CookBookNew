# P01 · 应用骨架与登录入口

> 说明：本文件为从《美食家园》产品需求派生的阶段实施安排，阶段划分与顺序是执行规划，非原始需求新增功能。
> 产品权威来源：`docs/requirements/product/01-roles-and-functions.md`、`02-pages.md`、`03-quality-and-appendices.md`。

## 阶段目的
在现有技术栈内建立统一的五个底部导航及必要的登录/注册入口，使未登录、已登录的用户路径可识别。统一用户体系，不建立独立商家身份。

## 本阶段完整工作范围
1. 按产品原型和已有项目结构实现/核实底部固定五入口：首页、菜谱、消息、订单、我的；现阶段仅完成容器与可明确交付的导航基础，不用伪完成页面替代后续阶段。
2. 处理“我的”页已明确的未登录入口：“登录/注册”“浏览应用”；保留后续个人中心页面的接入位置。
3. 基于项目既有登录组件完成登录/注册的必要导航及安全入口，尚无接口时记录无法联调的真实依赖；账号不存在“普通用户注册/创作者注册”双入口。
4. 登录状态切换时避免把前用户私有资料、聊天或订单数据显示给下一用户；权限校验不能只靠按钮显隐。
5. 未登录可浏览范围与登录后回跳属于【待确认】，在实现相关入口前取得准确决定；未确认不得假设所有私有功能可访问。
6. 新增或变更的页面适配小屏、字体缩放、错误/空状态，按钮与色调遵从当前项目已有风格。

## 验收要点
- 五导航名称与顺序与产品原文一致，基本切换/返回路径符合阶段范围；未交付页面不得标记为完成。
- 用户可进入登录/注册流程，“浏览应用”路径受已确认权限约束；没有账号角色重复注册。
- UI Gate 提供未登录→浏览→登录、切换标签、退出/切换账户的手动步骤及预期。
