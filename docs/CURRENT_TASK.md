# P04 · 菜谱详情与内容互动

> 说明：本文件为从《美食家园》产品需求派生的阶段实施安排，阶段划分与顺序是执行规划，非原始需求新增功能。
> 产品权威来源：`docs/requirements/product/01-roles-and-functions.md`、`02-pages.md`、`03-quality-and-appendices.md`。

## 阶段目的
完整展示有权访问的菜谱内容，并打通收藏、分享和评论等原有社交操作；预订动作仅保留准确入口，订单实现留在 P08。

## 本阶段完整工作范围
1. 菜谱详情展示图片、名称、作者、简介、食材、制作步骤；作者头像进入正确用户主页。
2. 支持已有的收藏、分享与评论能力；收藏结果与“我的收藏”的数据一致，具体收藏页面在 P09 整合。
3. 分享流程面向好友并重新校验可见性；“所有人可见”仅代表可浏览，不能因此向非好友开放预订。
4. 菜谱无权查看、已删除、加载失败三种情况的反馈要区分，避免暴露私密内容或错误缓存。
5. 保留“加入购物车（预订）”的原有入口意图，但在 P08 前不伪造已成功预订、不新增支付或独立购物车。无法达成有效预订时不能将其标成可用的已完成能力。
6. 评论区布局、分享载体、可见性边界中未定的交互在本阶段实施前基于原型或用户决定。

## 验收要点
- 详情信息完整且不同入口一致；作者、收藏、评论与分享正常工作。
- 好友可见菜谱不能被无权限用户打开；收藏操作与数据一致。
- UI Gate 覆盖有效/无权/已删/弱网状态以及返回导航。
