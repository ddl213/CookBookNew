# P03 · 个人菜谱发布与管理

> 说明：本文件为从《美食家园》产品需求派生的阶段实施安排，阶段划分与顺序是执行规划，非原始需求新增功能。
> 产品权威来源：`docs/requirements/product/01-roles-and-functions.md`、`02-pages.md`、`03-quality-and-appendices.md`。

## 阶段目的
交付用户自己的菜谱列表、创建、编辑、删除和可见性维护，保持“一人既可浏览又可创作”的产品模式。

## 本阶段完整工作范围
1. 菜谱主导航下以卡片/列表展示当前用户本人发布的菜谱，并提供“+”创建入口；点击条目进入已有/阶段内可用详情导航。
2. 创建、编辑、删除自己发布的菜谱；保存并展示菜品图片、名称、作者、简介、食材清单和制作步骤等原文明确字段。
3. 设置“好友可见 / 所有人可见”；查询和修改遵守所有者权限，公开列表/搜索/分享不能绕过可见性。
4. 根据当前设计稿或用户确认处理菜谱分类、字段必填、图片数量、编辑表单和删除后的订单展示；未知时暂停相应子任务，不自行设值。
5. 列表在创建/编辑/删除后保持数据一致；实现必要的空、加载与失败反馈，不虚构发布成功。
6. UI 采用现有项目组件及自适应布局，不复制设计稿固定宽高。

## 验收要点
- 本人菜谱正确展示，不能改删别人的菜谱；字段与权限展示准确。
- 两种可见性切换后，符合访问规则；原始保存失败时不能显示成功。
- UI Gate 覆盖创建→返回列表→编辑→更改可见性→删除、异常与空数据。
