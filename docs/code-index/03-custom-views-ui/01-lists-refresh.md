# 03-01 · 列表、Adapter 与刷新

> 返回分类首页：[03-custom-views-ui.md](../03-custom-views-ui.md)

**收录范围：**RecyclerView 装饰、下拉刷新、Builder 式 Adapter、ViewPager2 FragmentAdapter。

| ID | 类 / API / 资源入口 | 用途与优先复用场景 | 调用方式、前提和限制 | 定义文件（项目相对路径） | 真实调用位置 / 核查证据 |
| --- | --- | --- | --- | --- | --- |
| VIEW-001 | `RvDecoration` 及 `Builder` | 为普通列表和带刷新头的列表设置内容间距、分割线；刷新头不额外占装饰间距。 | `rv.addItemDecoration(RvDecoration.Builder().setVertical(30).setHorizontal(10).build())`；间距参数为 dp，可分别设置四边。跳过 `RefreshHeaderAdapter` 的间距与分割线，递归定位 `ConcatAdapter` 首个内容项。竖向 Grid 按实际 `SpanSizeLookup` 计算列间距和首内容行顶部间距；刷新头须占满一行（`RefreshRecyclerView` 自动处理），内容 span 必须在 `1..spanCount` 内。 | `subModules/lib_android_common/src/main/java/com/android/common/utils/RvDecoration.kt` | `CookBookChildFragment` 使用 `setVertical(30)`、红色分割线；`IndexChildFragment` 使用普通间距。测试：`RvDecorationRefreshTest.kt` 覆盖默认头高 0、首内容 top 42、下拉复位、普通列表、Grid 整行头及多 span、跳过头部分割线。 |
| VIEW-002 | `RefreshRecyclerView`、`IRefreshHeader`、`RefreshHeaderView`、`RefreshHeaderAdapter` | 下拉刷新列表；刷新头默认零高，下拉显示，完成后收起。 | 通过 `buildRefreshAdapter<T>(header = true)` 或手动 `ConcatAdapter(RefreshHeaderAdapter(header), dataAdapter)` 接入；`setOnRefreshListener` 请求数据，完成后调用 `refreshComplete()`。仅支持竖向手势；`footer = true` 会抛异常；Grid 头自动占满一行；`refreshComplete` 前保持 `REFRESHING` 状态，期间不再触发新刷新。 | `subModules/lib_android_common/src/main/java/com/android/common/base/adapter/refresh/RefreshRecyclerView.kt` | `CookBookChildFragment` 使用刷新列表并模拟 2 秒刷新；测试：`RefreshRecyclerViewTest.kt`、`RefreshHeaderViewTest.kt` 覆盖慢拉、取消、Grid、换头、完成时序。 |
| VIEW-003 | `AdapterBuilder<T>`、`BaseAdapter`、`SingleAdapter`、`MutableAdapter`、`BaseViewHolder` | 通过 Builder 配置单/多布局、Diff、点击、空布局初始化；数据用 `submitList/addItems` 提交。 | 主线程使用；必须设置 `setDiff` 和 `setLayout`，`bind`/`bindMulti` 二选一；多布局需 `setViewTypeDelegate`，绑定按 `holder.localViewType` 区分布局；点击回调的 `position` 为数据 Adapter 本地下标；列表做浅快照，元素应不可变。 | `subModules/lib_android_common/src/main/java/com/android/common/base/adapter/AdapterBuilder.kt` | `IndexFragment`、`IndexChildFragment`、`CookBookChildFragment` 使用；测试：`AdapterBuilderTest.kt`、`BaseAdapterTest.kt` 覆盖配置顺序、多布局、快照、点击、payload、footer 拒绝。 |
| VIEW-004 | `CommonFragmentAdapter`、`TabInfo` | ViewPager2 的 FragmentStateAdapter；按标签列表创建 Fragment 并注入参数。 | `TabInfo` 默认通过 `Class.forName(fragmentFullName)` 反射得到 Fragment 类，要求传入完整类名且 Fragment 有无参构造；`bundle` 为空时注入 `KEY_BUNDLE_PAGE_ID = id`。`setNewData` 会清空并 `notifyDataSetChanged`。 | `subModules/lib_android_common/src/main/java/com/android/common/base/CommonFragmentAdapter.kt` | `HomeFragment` 与 `CookBookFragment` 构造 `TabInfo` 并设置 `vp.adapter`；`TabInfo.kt` 定义 `fragmentFullName` 与 `bundle`。 |
