# 03-02 · 自定义 View 与样式控件

> 返回分类首页：[03-custom-views-ui.md](../03-custom-views-ui.md)

**收录范围：**标题栏、G 系列样式控件、进度组件、标签流、MagicIndicator 标题实现。

| ID | 类 / API / 资源入口 | 用途与优先复用场景 | 调用方式、前提和限制 | 定义文件（项目相对路径） | 真实调用位置 / 核查证据 |
| --- | --- | --- | --- | --- | --- |
| VIEW-005 | `TitleBar`（XML attrs） | 通用标题栏：左返回、标题、右文字或右图标，支持点击回调。 | XML 使用 `app:left_src`、`app:title_text`、`app:title_text_color`、`app:title_text_size`、`app:right_src`、`app:right_text`；右侧图标与右侧文字互斥。代码可 `setLeftSrc/setRightText/setTitle/setLeftClick/setRightClick`。继承 `FrameLayout`，内部 inflate `common_layout_title_bar`。 | `subModules/lib_android_common/src/main/java/com/android/common/view/TitleBar.kt` | `MineFragment`、`ChatFragment`、`OrderFragment`、`AddRecipesFragment` 布局使用；`CookBookFragment` 用空 View 作为沉浸式标题锚点。 |
| VIEW-006 | `BaseDrawable`、`GStyler`、`GStyleable` | 通用背景/边框/圆角/阴影/selected 状态样式引擎，供 G 系列控件通过组合复用。 | XML 属性见 `CommonGradientAttrs`：渐变、边框、四角圆角、阴影、selected 背景/边框。`GStyler` 会覆盖宿主 `android:background` 并接管绘制；阴影需软件层，`GStyler` 已自动设置。动态设置圆角/边框单位是 px，需先用 `dp()` 转换。不要直接调用 `View.setBackgroundResource`，否则会替换 `BaseDrawable`。 | `subModules/lib_android_common/src/main/java/com/android/common/view/base/BaseDrawable.kt` | `attrs_base_drawable.xml` 定义属性；`GConstraintLayout`、`GTextView`、`GImageView`、`GLinearLayout`、`GView`、`GEditText` 均持有 `GStyler`；`cookbook_layout_child.xml` 使用 `app:radius`。 |
| VIEW-007 | `GTextView`（文本渐变、selected 文字） | 支持两色/三色文字渐变、Drawable 填充文字、selected 纯色或渐变文字，同时具备 VIEW-006 背景能力。 | XML 使用 `text_start_color/text_center_color/text_end_color/text_color_angle`、`g_selected_text_*`、`text_drawable`；文字渐变依赖 View 宽高，尺寸为 0 时回落普通颜色。继承 `AppCompatTextView`，不能与普通 TextView 的属性冲突。 | `subModules/lib_android_common/src/main/java/com/android/common/view/base/GTextView.kt` | `index_fragment_index.xml` 的搜索框使用 `GTextView` 与 `app:radius`；`ExpandableFlowLayout` 动态创建 `GTextView`。 |
| VIEW-008 | `GConstraintLayout`、`GLinearLayout`、`GView`、`GEditText` | 在原有 ConstraintLayout/LinearLayout/View/EditText 基础上直接获得 VIEW-006 的背景、边框、圆角、阴影能力。 | 在 XML 中使用完整类名；attrs 与 VIEW-006 相同。`GEditText` 保留输入焦点与点击能力；`GView` 适合纯色/渐变背景块。动态样式通过 `getStyler()` 或 `setG*` 方法。 | `subModules/lib_android_common/src/main/java/com/android/common/view/base/GConstraintLayout.kt` | `cookbook_layout_child.xml`、`index_layout_index_child_horizontal_item.xml`、`index_layout_index_child_vertical_item.xml` 使用 `GConstraintLayout`；同目录 `GLinearLayout.kt`、`GView.kt`、`GEditText.kt` 为同级实现。 |
| VIEW-009 | `GImageView`（圆角裁剪、高斯模糊） | 对 background/src/foreground 统一圆角裁剪；可对当前 src 做 RenderScript 高斯模糊。 | XML `app:radius` 或四角圆角生效；`setGaussianBlur(radius)` 在 `post` 中异步处理，半径限制 0.1..25，基于原图避免重复模糊；`clearGaussianBlur()` 恢复。依赖已废弃的 RenderScript，高版本 Android 需关注兼容性。 | `subModules/lib_android_common/src/main/java/com/android/common/view/base/GImageView.kt` | `cookbook_layout_child.xml` 的 `iv_recipe_pic` 使用 `GImageView` 与 `app:radius`；`GaussianBlurHelper.kt` 为其实现。 |
| VIEW-010 | `CircleLoadingView` | 圆形进度/加载动画，可设置颜色、背景色、描边宽度、进度与收回阶段。 | XML attrs `circleColor`、`circleBgColor`、`strokeWidth`；代码 `setProgress(start, end, isRetract)`、`addProgress`、`resetProgress`、`startWithAnimator`。继承 `View`，需给定宽高。 | `subModules/lib_android_common/src/main/java/com/android/common/view/CircleLoadingView.kt` | `common_layout_refresh_header.xml` 使用 `process`；`RefreshHeaderView` 驱动进度和刷新动画。 |
| VIEW-011 | `ProcessView` | 沿圆角矩形路径绘制进度，支持 TOP/RIGHT/BOTTOM/LEFT 起始方向、背景、外边框、圆角与动画。 | XML attrs `progressColor/progressWidth/backgroundColor/backgroundWidth/outerBorderColor/outerBorderWidth/cornerRadius/startDirection`；代码 `setProgress(start, end)`、`addProgress`、`start(totalDuration)`、`startWithAnimator`、`resetProgress`。当前全仓未见调用，属于已定义未使用能力。 | `subModules/lib_android_common/src/main/java/com/android/common/view/ProcessView.kt` | 全仓检索仅定义与 `attrs.xml` 声明，无布局或页面调用。 |
| VIEW-012 | `ExpandableFlowLayout` | 标签流式布局，默认显示两行，可展开/收起，支持删除态。 | 通过 `setData(List<HistorySearchInfo>)` 填充 `GTextView` 标签并自动追加展开按钮；`setOnClickListener(OnClickListener)` 监听标签点击；`delete()` 切换删除态。依赖 `GImageView`、`GTextView`、`vector_arrow_down_24`、`vector_close_24`。当前全仓未见调用。 | `subModules/lib_android_common/src/main/java/com/android/common/view/ExpandableFlowLayout.kt` | 全仓检索仅定义与 `HistorySearchInfo` 数据类，无布局或页面调用。 |
| VIEW-016 | `CookBookTitleView`、`BottomBarItem`、`IndexTitleView` | MagicIndicator 的 `IPagerTitleView` 实现：标题选中加粗/下划线、底部导航图标选中态。 | 构造时传入 `title`；`onSelected/onDeselected` 由 MagicIndicator 调用。`CookBookTitleView` 与 `IndexTitleView` 结构相似但颜色资源不同；`BottomBarItem` 额外接收图标 `resId` 并绑定点击。`CookBookTitleView` 与 `BottomBarItem` 有实际调用；`IndexTitleView` 全仓未见调用。新增标签优先复用现有实现，不要复制第三份。 | `subModules/lib_cookbook/src/main/java/com/rhys/cookbook/view/CookBookTitleView.kt` | `CookBookFragment` 使用 `CookBookTitleView`；`HomeFragment` 使用 `BottomBarItem`；`subModules/lib_index/src/main/java/com/example/index/view/IndexTitleView.kt` 仅定义，无引用。 |
