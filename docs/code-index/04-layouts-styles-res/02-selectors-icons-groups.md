# 04-02 · 选中态 selector、图标与页面资源组

> 返回分类首页：[04-layouts-styles-res.md](../04-layouts-styles-res.md)。主题、基础颜色与按钮/头像见 [01-theme-colors-buttons.md](01-theme-colors-buttons.md)。

**收录范围：**chip/badge 选中态、聊天/订单页面资源组、Dialog 样式、底部导航与标题 selector、通用矢量图标。

**索引原则：**不为每张一次性图片逐行建条目；页面资源组只登记组入口与共性约束，不逐条复制无复用价值的 drawable。
