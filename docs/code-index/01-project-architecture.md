# 01 · 项目结构与架构约定

> 本类盘点状态：已盘点。已读取应用入口、各模块 Gradle、Manifest、路由生成器与页面基类；以下为可复用架构入口，不代表页面业务已完成。

**收录范围：**真实模块与 sourceSet、应用入口、导航容器、公共基类、路由与页面路径约定。

**索引原则：**只索引有助于定位/复用的项目级入口；页面是否存在以源码与调用为准，不把路由常量当作已实现页面。
