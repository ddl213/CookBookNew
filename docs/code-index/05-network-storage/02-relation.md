# 05-02 · 用户、好友关系与分页

> 返回分类首页：[05-network-storage.md](../05-network-storage.md)。基础网络/认证/存储见 [01-foundation-auth.md](01-foundation-auth.md)。

**收录范围：**用户与好友接口、关系 DTO、分页响应、关系错误映射、Response 校验、用户/好友 Repository。

**索引原则：**记录鉴权、分页边界、错误码和权限限制；好友关系与可见内容以后端判定为准，不在客户端推断。

| DATA-018 | `RelationErrorMapper.map` | 用户/好友/菜谱异常转可展示 `AuthException`，统一 401/403/404/409/429/5xx 与业务错误码。 | `internal object`，仅 `lib_network` 内可用；复用 DATA-009 的 `AuthException`（`code/message/httpStatus/isUnauthorized`），不记录请求体、密码或 token。业务码：`CANNOT_FRIEND_SELF`、`CANNOT_REMOVE_SELF`、`ALREADY_FRIENDS`、`FRIEND_REQUEST_EXISTS`、`REQUEST_NOT_PENDING`、`FRIEND_REQUEST_NOT_FOUND`、`FRIEND_NOT_FOUND`、`USER_NOT_FOUND`、`NOT_FRIENDS`、`RECIPE_FORBIDDEN`、`RECIPE_NOT_FOUND`、`VALIDATION_ERROR`、`FORBIDDEN`。HTTP：401 用调用方文案；400 通用不合法；403 无权限；404 不存在；409 状态冲突；429 频繁；>=500 服务不可用；`IOException` → 无法连接；其他 → 通用失败。菜谱详情页可据 `RECIPE_NOT_FOUND` 刷新或退出。 | `subModules/lib_network/src/main/java/com/example/network/RelationErrorMapper.kt` | `callRelationApi` 与 `requireSuccessful` 调用（DATA-019）；`RecipeRepository`（DATA-024）复用；`RelationApiCallTest` 覆盖 404/401（TEST-010）。 |
| DATA-019 | `callRelationApi`、`Response<T>.requireSuccessful` | 用户/好友 Repository 的统一协程异常转换；显式校验 `Response<T>` 的 2xx，避免 204 接口失败被当作成功。 | 均为 `internal`，仅 `lib_network` 内可用。`callRelationApi` 重抛 `CancellationException`，其余异常交 DATA-018；`requireSuccessful` 对非 2xx 用 `HttpException(response)` 走同一映射，保留 401/403/404 等状态。无重试、无请求去重；Repository 调用方需自行防重复提交并在操作后刷新。 | `subModules/lib_network/src/main/java/com/example/network/repository/RelationApiCall.kt` | `UserRepository`/`FriendRepository` 所有调用；`RelationApiCallTest` 3 例（TEST-010）。 |
| DATA-020 | `UserRepository.profile/search/recipes` | 用户数据访问层：用户主页、搜索、用户可见菜谱，含分页参数归一化。 | 方法均为 `suspend`；`profile/recipes` 要求 `userId > 0`（`require` 抛 `IllegalArgumentException`，不是 `AuthException`），`search` 的 keyword trim 后空转 null；`page.coerceAtLeast(1)`，`pageSize.coerceIn(1, 50)`，默认 20（`DEFAULT_PAGE_SIZE`/`MAX_PAGE_SIZE`）。不做权限判定、不缓存；异常经 DATA-019；UI 需在协程调用并处理 `AuthException`。 | `subModules/lib_network/src/main/java/com/example/network/repository/UserRepository.kt` | `UserProfileFragment` 使用 `profile/recipes`；`FriendSearchFragment` 使用 `search`。 |
| DATA-021 | `FriendRepository`、`FriendRequestDirection` | 好友数据访问层：好友列表、申请发送/查询/接受/拒绝、解除好友。 | 方法均为 `suspend`；`listFriends/listRequests` 分页归一化同 DATA-020；`direction` 为 `INCOMING/OUTGOING`，`status` 默认 `STATUS_ALL=all`，另有 `STATUS_PENDING=pending`；`sendRequest` 要求 `toUserId > 0`，message trim 后空转 null；`accept/reject/delete` 要求 id > 0；`deleteFriend` 调 `requireSuccessful` 处理 204。不缓存状态，操作后由页面重新拉取；ID 非法时 `require` 抛 `IllegalArgumentException`。 | `subModules/lib_network/src/main/java/com/example/network/repository/FriendRepository.kt` | `FriendsFragment`、`FriendRequestsFragment`、`UserProfileFragment` 使用；API 见 DATA-013、异常见 DATA-019。 |
