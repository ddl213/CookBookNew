# 05-01 · 数据模型、认证与存储

> 返回分类首页：[05-network-storage.md](../05-network-storage.md)。本子表保留首次盘点与 `P01-T02` 增量条目；好友/用户接口见 [02-relation.md](02-relation.md)。

**收录范围：**本地展示模型、Room 骨架、网络基址、共享 Retrofit 客户端、认证接口与 DTO、认证错误映射、认证 Repository、MMKV 会话存储。

**索引原则：**记录权限、异常/重试、线程和数据安全边界；骨架与未接线能力必须注明。

| ID | 类 / API / 资源入口 | 用途与优先复用场景 | 调用方式、前提和限制 | 定义文件（项目相对路径） | 真实调用位置 / 核查证据 |
| --- | --- | --- | --- | --- | --- |
| DATA-001 | 数据模型 `Recipe`、`User`、`HomeFeedItem`、`Following` | 页面展示用的菜谱、用户、好友动态、关注关系数据载体；可作为后续接口 DTO 的起点。 | 纯 Kotlin `data class`，无序列化注解、无网络字段映射；`Recipe` 包含 id/userId/name/imageUrl/desc/publishDate/likes/collections/commentsCount；`User` 包含 bio/fans/followingCount/recipesCount/isFollowing。当前仅被本地假数据构造，不能据此认定已对接后端；认证链路使用 `UserDto`（DATA-007），关系链路使用 DATA-014，不要混用。 | `subModules/lib_network/src/main/java/com/example/network/bean/Recipe.kt` | `CookBookChildFragment`、`IndexChildFragment` 用硬编码列表构造；`Following` 仅定义，无调用。同目录 `User.kt`、`HomeFeedItem.kt`、`Following.kt`。 |
| DATA-002 | `CookBookDB` Room 数据库骨架 | 预留给菜谱本地持久化；当前不是可用数据库。 | 仅 `abstract class CookBookDB : RoomDatabase()`，没有 `@Database`、entities、DAO、`Room.databaseBuilder` 或迁移；模块虽引入 Room runtime/ktx/compiler，但无实际建库入口。新增持久化前需先定义实体、DAO、版本与迁移策略，并确认产品允许的本地数据范围。 | `subModules/lib_cookbook/src/main/java/com/rhys/cookbook/room/CookBookDB.kt` | 全仓检索无 `Room.databaseBuilder`、`@Database`、`@Dao`、`@Entity` 或 `CookBookDB` 调用；`lib_cookbook/build.gradle.kts` 仅声明依赖与 KSP。 |
| DATA-003 | `NetworkConfig.baseUrl`、`resolveMediaUrl(value: String?)` | 配置后端基址；把后端返回的 `/uploads/...` 等媒体路径解析成可加载 URL，供头像、图片复用。 | `baseUrl` 初始值来自 `lib_network` 的 `BuildConfig.API_BASE_URL`：`apiBaseUrl` Gradle 属性在构建时写入，未指定时默认 `http://10.0.2.2:3000/api/v1/`（仅适用于模拟器访问宿主机）。真机 USB 调试先执行 `adb reverse tcp:3000 tcp:3000`，再用 `-PapiBaseUrl=http://127.0.0.1:3000/api/v1/` 构建；局域网调试用开发机 IP（如 `http://192.168.1.10:3000/api/v1/`）并让后端监听 `0.0.0.0`。属性在构建期固化，改值需重新构建对应变体；运行时仍可改 `baseUrl`，但必须在首次访问 `ApiClient` 的任一 API 前设置，Retrofit 首次创建后不再读取新值。`resolveMediaUrl`：null/空白→null；`http://`/`https://` 原样返回；以 `/` 开头→拼接 baseUrl 的 scheme+host+port（丢弃 `/api/v1/` 等路径）；其他相对值原样返回；baseUrl 解析失败时回退原值，不抛异常。非线程安全配置项，应在启动阶段一次性设置。 | `subModules/lib_network/src/main/java/com/example/network/NetworkConfig.kt` | `ApiClient` 使用 `baseUrl`；`MineFragment`、`RelationUiSupport`、`UserProfileFragment` 用 `resolveMediaUrl`；`NetworkConfigTest` 5 例（TEST-006）。 |
| DATA-004 | `ApiClient.authApi/userApi/friendApi` | 全局唯一的 OkHttp/Retrofit 客户端，统一超时、鉴权头与 JSON 转换；新增后端接口应复用同一客户端。 | Kotlin `object` + `lazy`；共享一个 `Retrofit` 与 `OkHttpClient`，首次访问任一 API 时用当时的 `NetworkConfig.baseUrl` 创建并固化。OkHttp 连接/读/写超时均 15 秒；每次请求从 `SessionStore.token()` 读取 token，非空才追加 `Authorization: Bearer <token>`；未接入 HttpLoggingInterceptor，避免密码/token 进入日志；无重试、无证书固定。当前暴露 `authApi`、`userApi`、`friendApi`；`retrofit` 为 private，新增接口需在本类补 `val xxxApi`。 | `subModules/lib_network/src/main/java/com/example/network/ApiClient.kt` | `AuthRepository` 用 `authApi`（DATA-010）；`UserRepository` 用 `userApi`（DATA-020）；`FriendRepository` 用 `friendApi`（DATA-021）；`SessionStore.token()` 为拦截器提供 token。 |
| DATA-005 | `AuthApi.register/login/me`（suspend） | 认证接口定义：注册、登录、获取当前用户。 | Retrofit `suspend` 函数，必须在协程中调用；baseUrl 已含 `/api/v1/`，接口使用 `auth/register`、`auth/login`、`auth/me` 相对路径。非 2xx 抛 `HttpException`，由 DATA-009 统一转换；`me()` 依赖 DATA-004 自动附加 token，未登录会得到 401。不要在 UI 直接调用，走 DATA-010。 | `subModules/lib_network/src/main/java/com/example/network/api/AuthApi.kt` | `AuthRepository.login/register/me` 调用三个方法。 |
| DATA-006 | 认证请求 DTO `LoginRequest`、`RegisterRequest` | 登录/注册 JSON 请求体，字段与 CookBookService 对齐。 | `LoginRequest(username, password)`；`RegisterRequest(username, password, nickname: String? = null)`，昵称为空时由后端回退用户名。无序列化注解，依赖 Gson 字段同名；此处不做校验，UI 预校验见 BIZ-003（`AuthValidator`），后端仍是最终校验方。 | `subModules/lib_network/src/main/java/com/example/network/bean/LoginRequest.kt` | `AuthRepository.login/register` 构造；同目录 `RegisterRequest.kt`；`RegisterFragment` 只传 trim 后的非空昵称。 |
| DATA-007 | 认证响应 DTO `AuthResponse`、`UserDto` | 登录/注册成功返回 token 与公开用户资料；`UserDto` 是当前用户展示与会话缓存的规范模型。 | `AuthResponse(token: String, user: UserDto)`；`UserDto(id: Long, username, nickname, avatar?, bio?, createdAt?)`，`avatar/bio/createdAt` 可空，`displayName` 在昵称为空时回退 `username`。不要与本地展示模型 `User`（DATA-001）或关系 DTO（DATA-014）混用；字段名变化需同步后端。 | `subModules/lib_network/src/main/java/com/example/network/bean/AuthResponse.kt` | `AuthRepository` 返回并保存；`SessionStore` 以 JSON 缓存；`SessionManager` 更新 `AuthState.LoggedIn`；`MineFragment` 读取。同目录 `UserDto.kt`。 |
| DATA-008 | 错误响应 DTO `ApiErrorResponse`、`ApiError`、`ApiErrorDetail` | 解析后端统一错误结构 `{ error: { code, message, details? } }`，供认证与关系错误映射使用。 | 字段全部可空以容忍后端差异；`details` 用于 400 字段校验错误（`path`、`message`、`code`）。只在 DATA-009、DATA-018 内部解析，不建议 UI 直接消费。 | `subModules/lib_network/src/main/java/com/example/network/bean/ApiErrorResponse.kt` | `AuthErrorMapper`（DATA-009）与 `RelationErrorMapper`（DATA-018）解析；见 TEST-010。 |
| DATA-009 | `AuthException`、`AuthErrorMapper` | 把认证网络/HTTP 异常转换为可展示异常；统一 401、用户名占用、400 校验、429 与网络断开文案。 | `AuthException(code, message, httpStatus?, cause?)` 的 `message` 已是用户可读文案，不含堆栈或服务端内部细节；`isUnauthorized` 判断 HTTP 401，也被关系接口复用。`AuthErrorMapper` 是 `internal object`，只能在 `lib_network` 内使用；它不记录请求体、密码或 token。映射规则：401 使用调用方传入文案；`USERNAME_TAKEN`；400 优先拼接 `details`；429；其余用服务端 message 或 `HTTP_<status>`；`IOException` → 无法连接服务器；其他 → 通用失败。关系接口使用独立的 DATA-018。 | `subModules/lib_network/src/main/java/com/example/network/AuthException.kt` | `AuthRepository.call` 映射并重抛 `CancellationException`；`SessionManager.restore` 依赖 `isUnauthorized`；同目录 `AuthErrorMapper.kt`。 |
| DATA-010 | `AuthRepository` | 认证数据访问层：封装接口调用、错误映射与会话读写，不含 UI。 | `suspend login/register/me` 必须在协程调用；成功不自动保存，需显式 `saveSession(AuthResponse)`；`clearSession()`、`cachedUser()`、`currentToken()` 同步读取 MMKV。取消异常原样抛出；其他异常转成 DATA-009。无内置重试、无请求去重，重复提交需 UI 防抖（登录/注册页已有 `submitting`）。 | `subModules/lib_network/src/main/java/com/example/network/repository/AuthRepository.kt` | `SessionManager` 持有唯一实例并调用 login/register/me/saveSession/clearSession/cachedUser/currentToken（见 BIZ-001）。 |
| DATA-011 | `SessionStore`（MMKV） | 持久化登录 token 与用户公开资料 JSON，供启动恢复与鉴权拦截器读取。 | Kotlin `object`；Key 固定 `auth_token`、`auth_user`；依赖 `MMKVUtils` 与 `MyApplication` 的 `MMKV.initialize`。`token()` 对空白返回 null；`user()` 对空值/损坏 JSON 返回 null；`clear()` 删除两个 Key。当前**不额外加密** token，注意不要写入日志或导出；不要绕过本类直接拼 Key。 | `subModules/lib_network/src/main/java/com/example/network/session/SessionStore.kt` | `ApiClient` 拦截器读 token；`AuthRepository.saveSession/clearSession/cachedUser/currentToken`；`SessionManager`；存储工具见 UTIL-002。 |
