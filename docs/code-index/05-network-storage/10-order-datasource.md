# 05-10 · 可替换订单数据源

> 返回分类首页：[05-network-storage.md](../05-network-storage.md)。订单接口/DTO/配置见 [09-order-network.md](09-order-network.md)，Repository 与待确认存储见 [11-order-repository-pending.md](11-order-repository-pending.md)。

**收录范围：**`OrderDataSource` 可替换边界与参数归一化、Remote/Mock 实现、Mock 共享存储、数据源工厂、订单 actor/owner 来源。

**索引原则：**页面/Repository 只依赖 `OrderDataSource`；Mock 只用于本地开发与验收且必须明确标识；客户端预校验不能替代服务端好友关系、参与方、动作权限、版本与幂等判定。
