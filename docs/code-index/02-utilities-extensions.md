# 02 · 通用工具类与扩展方法

> 本类盘点状态：已盘点。已核对 `lib_android_common` 的工具、扩展与调用点；以下方法均有真实源码入口，未证实使用的项已注明。

**收录范围：**通用日志、键值存储、密度转换、View 可见性、图片加载、RecyclerView 布局与 MagicIndicator 绑定、Application 持有。

**索引原则：**记录真实可调用方法及入参/返回值和线程/Context 限制；不同模块同名方法以路径区分。

| ID | 类 / API / 资源入口 | 用途与优先复用场景 | 调用方式、前提和限制 | 定义文件（项目相对路径） | 真实调用位置 / 核查证据 |
| --- | --- | --- | --- | --- | --- |
| UTIL-001 | `LogUtils`（`v/d/i/w/e`、级别、Tag 过滤、计数限制） | 统一日志输出；自动补充调用类/方法、文件与行号，支持全局级别和 Tag 过滤。 | Kotlin `object`；默认级别 `DEBUG`、基础 Tag `myLog`；`getCallerInfo` 会遍历堆栈并额外打印 `Log.e` 调试点，日志量较大。可在发布包调高 `setLogLevel`。参数重载较多，注意不要误用 `d(vararg args)` 与 `d(msg, tag)`。 | `subModules/lib_android_common/src/main/java/com/android/common/utils/LogUtils.kt` | `HomeFragment`、`CookBookFragment`、`IndexFragment`、`RefreshHeaderView`、`BaseViewModel` 等直接调用。 |
| UTIL-002 | `MMKVUtils` 键值存储 | 保存 int/long/float/double/boolean/String/Parcelable，并支持删除与清空；当前用于持久化登录 token 与用户公开资料。 | 单例懒加载 `MMKV.defaultMMKV()`；`MyApplication.onCreate` 已先调用 `MMKV.initialize(this)`，未初始化时访问会失败。`getString(key)` 默认返回空串，读取后仍需按空值处理；无类型安全与字段版本迁移，Key 需全局唯一。当前 `SessionStore` 直接存 token 与用户 JSON，未额外加密。 | `subModules/lib_android_common/src/main/java/com/android/common/utils/MMKVUtils.kt` | `app/src/main/java/com/rhys/main/MyApplication.kt` 初始化；`subModules/lib_network/src/main/java/com/example/network/session/SessionStore.kt` 调用 `getString/setString/removeValueForKey`（见 DATA-011）。 |
| UTIL-003 | `DensityUtil`、`Int.dp()`、`Int.sp()`、`Float.dp()`、`Float.sp()` | dp/sp 与 px 互转，供代码中动态尺寸、圆角、间距使用。 | 使用 `Resources.getSystem().displayMetrics`，不依赖当前 Activity/Context；系统字体缩放会影响 `sp()`；返回 `Float`，需要整数像素时调用 `.toInt()`。 | `subModules/lib_android_common/src/main/java/com/android/common/ext/DenisyExt.kt` | `RefreshHeaderView`、`RvDecoration`、`ExpandableFlowLayout`、`CookBookFragment`、`CookBookDetailFragment` 使用。 |
| UTIL-004 | `View.visible()`、`View.gone()`、`Fragment.finish()` | 幂等地切换可见性；在 Fragment 中返回上一页。 | `visible/gone` 只在状态不同时赋值；`Fragment.finish()` 使用 `findNavController().popBackStack()`，要求 Fragment 已附着 NavController，不能替代 Activity 的 `finish()`。 | `subModules/lib_android_common/src/main/java/com/android/common/ext/KT.kt` | `CookBookTitleView`、`IndexTitleView`、`IndexFragment`、`TitleBar` 使用可见性扩展；`LoginFragment`、`RegisterFragment`、`MineFragment` 用于错误提示、加载态与登录态区块切换。 |
| UTIL-005 | `ImageView.load(url: String/Uri/Int)` | 用 Glide 加载网络、Uri 或资源图片；统一空图和失败日志入口。 | 主线程调用；Glide 生命周期绑定当前 View。`Int` 重载会设置错误色 `color_0a80ed` 并打印加载失败日志，但未设置占位图。网络加载需 Manifest `INTERNET` 权限；当前已声明。 | `subModules/lib_android_common/src/main/java/com/android/common/ext/ViewExt.kt` | `CookBookChildFragment` 加载 `RecipeDto.imageUrl`；`CookBookDetailFragment` 加载封面/作者头像，`ShareFriendDialog` 加载好友头像；`IndexUiSupport.bindIndexRecipeCard/bindIndexAvatar` 供首页/搜索页加载菜谱图与头像；`IndexChildFragment` 加载菜谱图和 `R.drawable.img_home_top`；`MineFragment.bindUser` 加载经 `NetworkConfig.resolveMediaUrl` 处理后的头像 URL。 |
| UTIL-006 | `RecyclerView.liner()/grid()`、`RefreshRecyclerView.liner()/grid()` | 一行代码设置线性/网格 LayoutManager，支持方向与 reverse。 | 会替换当前 `layoutManager`；默认竖向、`reverse = false`；网格默认 2 列。设置后若已有 Adapter，`RefreshRecyclerView` 会重新同步刷新头 SpanSizeLookup。 | `subModules/lib_android_common/src/main/java/com/android/common/ext/RecyclerViewExt.kt` | `IndexFragment`、`IndexChildFragment`、`CookBookChildFragment` 使用；配套列表提交扩展同文件。 |
| UTIL-007 | `MagicIndicator.setNavigator(...)`、`ViewPager2.attach(indicator)` | 快速绑定 MagicIndicator 与 ViewPager2，统一页面切换回调。 | `setNavigator` 使用 `CommonNavigator`，默认 `isAdjustMode = true`，不提供指示器（`getIndicator` 返回 null），标题 View 由调用方创建；`attach` 会注册一个无法注销的 `OnPageChangeCallback`，重复调用会重复注册。 | `subModules/lib_android_common/src/main/java/com/android/common/ext/KT.kt` | `HomeFragment` 绑定五导航；`CookBookFragment` 绑定已发布/草稿标签。 |
| UTIL-008 | `AppHelper` | 持有全局 `Application` 实例，供无 Context 场景取应用上下文。 | 必须在 `Application.onCreate` 调用 `AppHelper.init(this)`；`lateinit` 未初始化时访问会抛异常。当前仅在 `MyApplication` 初始化，未见业务读取。 | `subModules/lib_android_common/src/main/java/com/android/common/helper/AppHelper.kt` | `app/src/main/java/com/rhys/main/MyApplication.kt` 调用 `AppHelper.init(this)`；全仓无 `AppHelper.application` 读取。 |
