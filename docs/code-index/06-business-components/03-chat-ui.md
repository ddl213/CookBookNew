**P10-T02-F01 通知页核实：**`ChatNotificationsFragment` 仍复用 BIZ-012 的标题/正文/时间展示规则，数据源为 DATA-071 `OrderNotificationRepository.fetchAll`：Remote 走不带 `category` 的 `notifications?page/pageSize`（`pageSize=20`），同时展示订单通知与 `recipe_share` 菜谱分享；Mock 跟随订单 `OrderDataSourceConfig` 读 DATA-056 共享事件（全部/仅订单共用同一批，不伪造分享通知）。支持下拉刷新、滚动分页（跳过连续空页）、空/加载/错误、`isMock` 演示横幅与 `onResume` 返回刷新；点击按 `orderId` 以 `KEY_BUNDLE_ORDER_ID` 跳 `PAGE_ORDER_DETAIL`、按 `recipeId` 以 `KEY_BUNDLE_RECIPE_ID` 跳 `PAGE_COOK_BOOK_DETAIL`，两者都无效时提示 `chat_notification_unavailable`，不伪造参数；标题与入口文案统一为“通知”，入口说明包含菜谱分享。本期不做未读/已读、红点或推送。页面结构与生命周期细节见 ARCH-017，不为此新增重复业务组件条目。
