**收录范围：**`lib_order` 订单列表与详情共用的状态/动作文案、`allowedActions` 过滤、计数摘要、列表去重、对方角色与时间格式化纯逻辑。

**索引原则：**只登记真实调用且有复用价值的纯函数；不把服务端 `allowedActions` 当作可自行扩展的权限，不推断未知状态/动作。
