# 07-01 · 版本目录、公共库与工具链

> 返回分类首页：[07-dependencies-build.md](../07-dependencies-build.md)。模块构建与网络/数据源配置见 [02-module-builds.md](02-module-builds.md)。

**收录范围：**版本目录、公共 UI/基础库、Room 骨架、选择器、路由编译、校验脚本、仓库/JDK 配置。

**索引原则：**以实际仓库文件为源；写清库用途与版本来源，不照网上常见版本猜测。
