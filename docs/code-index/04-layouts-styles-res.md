# 04 · 布局、样式与资源

> 本类盘点状态：已盘点。已核对 `app` 与各模块 `res` 目录；只登记确实可复用的主题、颜色、selector、样式与图标。`TitleBar`、刷新头等布局由对应 View 自行 inflate，能力见分类 03，不在此重复。

**收录范围：**重复使用的 XML 布局、主题、颜色、selector、style、attrs、通用图标。

**索引原则：**不为每张一次性图片逐行建条目；优先登记页面通用规范和确实可复用资源。
