# P08 · 菜品预订与双向订单管理

> 说明：本文件为从《美食家园》产品需求派生的阶段实施安排；2026-10-25 用户确认的订单业务补充以以下契约为准。
> 产品权威来源：`docs/requirements/product/01-roles-and-functions.md`、`02-pages.md`、`03-quality-and-appendices.md`。
> P08 订单契约：`docs/phases/P08-reservation-order/04-order-contract.md`（相对仓库根目录；含已确认业务、目标接口、后端迁移、客户端接入和专属验收矩阵）。

## 阶段目的
完成好友免费多菜品预订：确认后形成同一关联订单，各菜品独立接受、拒绝、备货、取消与确认取货，双方视角保持状态一致。

## 本阶段完整工作范围
1. 菜谱详情和好友可预订菜品列表沿用“加入购物车”按钮，进入**预订确认弹窗**，支持同一好友多菜品、数量和整单备注。
2. 菜品预订详情显示好友资料及符合权限的菜品；评分、预计送达时间无真实来源时显示“暂无”。
3. 确认提交成功后，预订方“我的订单”与提供方“我的销售”访问同一笔关联订单。两标签展示相应用户有权操作的订单。
4. 提供方按明细接受/拒绝、确认备货完成；预订方取消待接受明细、确认取货。整单汇总、终态和原子整单取消按订单契约执行。
5. 创建及状态操作覆盖重复请求、超时恢复、回查与并发冲突；服务端裁定最终权限和状态，双端按同一契约保持一致。
6. 保存历史快照并迁移旧单菜品订单；菜谱变更及解除好友对已有订单的影响按已确认契约执行。
7. 接入六类订单事件与 P07 独立预订通知；完成 Mock/Remote 数据层、页面和本地真实后端联调。

## 验收要点
- 有权限好友可以确认预订；非好友、无权限或不可预订不能下单。
- 两种订单视角及明细/整单状态一致，取货闭环、取消和混合终态正确；异常/重复请求不产生伪成功或重复业务。
- 按订单契约的 P08 专属矩阵验证迁移、通知和双用户链路；Mock、真实后端及 UI 结果分别可核验。
