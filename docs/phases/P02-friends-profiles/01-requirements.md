# P02 · 好友关系与用户主页

> 说明：本文件为从《美食家园》产品需求派生的阶段实施安排，阶段划分与顺序是执行规划，非原始需求新增功能。
> 产品权威来源：`docs/requirements/product/01-roles-and-functions.md`、`02-pages.md`、`03-quality-and-appendices.md`。

## 阶段目的
让已有好友功能入口与个人/好友/创作者主页的身份数据形成可核验的关系基础，为聊天、好友可见菜谱和预订权限提供前置条件。

## 本阶段完整工作范围
1. 在用户有权访问的页面展示头像、昵称、ID 等已明确字段，并支持从相关作者/创作者入口到正确用户主页的导航基础。
2. 落实“我的好友”已有入口关联的好友列表/关系查询能力，遵守项目真实好友数据与当前用户身份。
3. 明确区分好友、非好友、未登录三类操作权限；不可仅凭公开菜谱或陌生人主页开放预订。
4. 好友申请、解除、拉黑、搜索添加、好友主页可见字段等具体规则【待确认】。仅按明确原型/用户决定实现，不强行生成完整社交体系。
5. 好友关系改变后，后续菜谱可见性、聊天和预订的访问权限须能重新判定。必要时先定义只供下阶段调用的稳定接口，不提前创建业务页面。

## 验收要点
- 正确展示用户与好友信息，未登录和非好友无法访问受限制的数据。
- 关联入口能定位相应用户，权限变化能够触发有效的数据访问边界。
- UI Gate 提供不同关系/登录状态下的可见性与返回路径检查。
