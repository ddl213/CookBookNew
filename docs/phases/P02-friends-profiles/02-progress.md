## 用户决策（2026-10-22）

1. 好友建立：申请-接受/拒绝。搜索用户 → 发送申请 → 对方接受/拒绝；复用 CookBookService 现有接口。
2. 解除好友后：**保留历史聊天可读**，但禁止新消息；好友可见菜谱与预订权限立即失效；历史订单双方仍可查。
3. 用户主页：展示头像、昵称、@username、简介、好友数、可见菜谱数、当前查看者有权看到的菜谱列表。
4. P02 范围：好友列表 + 用户搜索/好友申请/接受/拒绝 + 用户主页。

### P02-T01 实施范围

- `lib_network`：增加用户/好友/菜谱查询 API、DTO、Repository、分页与错误映射；复用现有 ApiClient/Auth 错误映射能力。
- 新增 `lib_relation` 模块（或等价单一好友/主页模块）：好友列表、用户搜索、好友申请列表、用户主页、解除好友、加载/空/错误状态。
- `lib_campaign_common`：新增好友/用户主页路由常量。
- `lib_mine`：“我的好友”入口接到好友列表；其余占位不动。
- 用户主页入口：好友列表/搜索结果/申请列表可进入；后续菜谱作者头像复用同一路由。
- 权限：未登录、非好友、好友三态区分；后端仍是最终校验方；页面不展示无权数据。
- UI 规范：ConstraintLayout 优先，禁止新增 FrameLayout；复用 TitleBar/GImageView/adapter DSL/颜色；长文本 ellipsize；加载/空/错误状态。
