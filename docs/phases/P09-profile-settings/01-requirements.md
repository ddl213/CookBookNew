# P09 · 个人中心、收藏与设置整合

> 说明：本文件为从《美食家园》产品需求派生的阶段实施安排，阶段划分与顺序是执行规划，非原始需求新增功能。
> 产品权威来源：`docs/requirements/product/01-roles-and-functions.md`、`02-pages.md`、`03-quality-and-appendices.md`。

## 阶段目的
交付完整“我的”个人中心，整合已有功能入口与设置能力，保证从本人页面访问收藏、好友和订单等内容时信息一致。

## 本阶段完整工作范围
1. “我的”主界面展示头像、昵称、用户 ID，并设置我的收藏、我的好友、我的订单等既有入口，设置按钮进入设置页。
2. 个人资料发生更新后，正确刷新个人页、好友/创作者卡片和菜谱作者等显示位置，不用其他用户资料替代失败加载。
3. 设置提供需求原有的隐私设置、通知设置和应用帮助入口；隐私具体开关及陌生人隐藏范围仍按已确认内容做，不自行新增细分选项。
4. 未登录时按设计展示“登录/注册”和“浏览应用”，并遵守 P01 的登录访问决定。
5. 我的收藏与菜谱详情收藏状态同步；我的好友与 P02 的实际关系一致；我的订单与 P08 的同一订单来源一致，不另建影子数据。
6. 提供通用加载/无内容/错误与返回路径处理，复用同 App 的主流二级页和按钮视觉。

## 验收要点
- 所有入口到达正确功能，资料一致；收藏、好友、订单可跨页面刷新并保持一致。
- 设置项按已确认需求展示；未登录状态、隐私权限和故障反馈准确。
- UI Gate 提供从“我的”进入并返回每个入口、修改资料/收藏后刷新及退出登录互测步骤。
