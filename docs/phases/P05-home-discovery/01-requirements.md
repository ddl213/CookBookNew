# P05 · 首页推荐、分类与搜索

> 说明：本文件为从《美食家园》产品需求派生的阶段实施安排，阶段划分与顺序是执行规划，非原始需求新增功能。
> 产品权威来源：`docs/requirements/product/01-roles-and-functions.md`、`02-pages.md`、`03-quality-and-appendices.md`。

## 阶段目的
按原有主页结构提供推荐、好友动态、热门、分类和搜索入口，并实现上滑折叠搜索框的具体交互。

## 本阶段完整工作范围
1. 首页展示菜谱卡片的图片、名称、作者，包含推荐内容和好友动态；用户可进入详情，好友动态头像可进入好友主页。
2. 提供推荐、好友动态、热门、家常菜、早餐、甜品等分类标签并切换对应内容；搜索菜谱或用户及搜索结果入口。
3. 上滑内容时搜索框渐进折叠，完成后分类标签右侧出现可用搜索按钮；宽度变化和不同字号不能产生遮挡、重叠或点击失效。
4. 好友动态与公开菜谱必须依权限过滤；不同标签切换后展示与当前标签相符，不能泄露好友专属内容。
5. 个性化推荐目标沿用“偏好与浏览历史”，但具体权重/冷启动/热门统计属于【待确认】。可以对接已有合规推荐服务，不可将未确认模拟排序说成算法已完成。
6. 页面提供加载、无结果、网络失败与必要的重试交互；图片加载失败不拖垮整个页面。

## 验收要点
- 首页折叠前后搜索入口可用，标签内容切换与跳转正确。
- 好友动态与公开列表符合权限，长文字和屏幕尺寸变化不影响关键操作。
- UI Gate 给出逐步滑动、切换、搜索、打开详情/用户主页与失败状态手动测试。
