# P06 · 美食创作者发现与公共菜谱

> 说明：本文件为从《美食家园》产品需求派生的阶段实施安排，阶段划分与顺序是执行规划，非原始需求新增功能。
> 产品权威来源：`docs/requirements/product/01-roles-and-functions.md`、`02-pages.md`、`03-quality-and-appendices.md`。

## 阶段目的
落实已有“推荐大师 / 公开菜谱”页面与创作者发现能力，让用户访问公开内容和相应创作者主页。

## 本阶段完整工作范围
1. 页面保留两个标签“推荐大师”“公开菜谱”，分别展示创作者卡片与所有人可见的菜谱内容。
2. 创作者卡片展示头像、昵称，点击进入对应创作者主页；公开菜谱卡片进入正确菜谱详情。
3. 原文提到推荐或附近用户。推荐口径、附近的定位来源/距离、评分或筛选资格属于【待确认】，若实际需要定位，应遵守权限与隐私，不能伪造距离或认证标准。
4. 列表数据与菜谱最新可见性一致；不可把好友专属菜谱混入公开列表，或者将公共可读等同于陌生人可订。
5. 提供空、加载、失败以及权限缺失状态，保证两个标签间切换与返回行为清楚。

## 验收要点
- 标签筛选与内容一致，点击卡片导航正确；权限与错误场景没有泄漏。
- 如实现“附近”，以用户确认且真实可用的数据/权限验证；未确认时准确记录未完成约束。
- UI Gate 包含标签、点击、返回和定位权限场景（适用时）。
